# Роли и права доступа

## Роли

| Роль | Код | Как назначается | Где работает |
|---|---|---|---|
| Организатор | `organizer` (группа Django или superuser) | Глобальная роль | Компьютер. На ширине < 1024 px экраны организатора заменяются заглушкой |
| Эксперт | `expert` (группа Django) | Группа добавляется при назначении в аудиторию; право оценивать проверяется по записи в `section_experts` | Телефон (основной сценарий), компьютер |
| Тренер | `trainer` (группа Django) | Группа добавляется при назначении тренером направления; право на материалы проверяется по направлению | Любой |
| Студент | `student` (группа Django) | Глобальная роль; состав команды — из витрины | Любой |
| Наставник | `mentor` (производная, не группа) | Выводится из состава команды в витрине (A28); не связана с группой `manager` (ПР1) | Любой |

- У пользователя может быть несколько ролей одновременно (например, организатор и эксперт). Переключателя ролей нет: меню — объединение пунктов всех ролей. Бэкенд отдаёт `roles[]` в `GET /api/auth/me/`; меню собирает фронт.
- Права «эксперт аудитории», «тренер направления» и «наставник команды» проверяются на уровне объекта, а не только роли.
- Вход: `authenticate_user` на бэкенде сейчас заглушка, а согласие по 152-ФЗ выдаёт группу `student` всем. Это заменяется до релиза по решению ПР1 ([../decisions.md](../decisions.md)): студенты и наставники сопоставляются с витриной по корпоративной почте, внешние эксперты и тренеры входят по приглашению организатора. Группа `manager` для прав в новых модулях не используется.

## Пункты меню

| Пункт | Кто видит |
|---|---|
| Личный кабинет (с блоком «Ближайшие мероприятия») | все |
| Мероприятия, Оценочные листы | организатор |
| Мои предзащиты (список назначенных аудиторий; в прототипе «Оценка команд») | эксперт |
| Мои мероприятия (направления и материалы) | тренер |
| Расписание (отметки по своим командам) | наставник |

## Матрица доступа

✔ — можно, ◐ — только свои объекты, ✖ — нельзя (ответ `403`, на фронте экран «Нет доступа»).

| Действие | Орг. | Эксперт | Тренер | Студент | Наставник |
|---|---|---|---|---|---|
| Создать, редактировать, опубликовать мероприятие | ✔ | ✖ | ✖ | ✖ | ✖ |
| Создать и редактировать оценочный лист | ✔ | ✖ | ✖ | ✖ | ✖ |
| Управлять аудиториями, экспертами, командами | ✔ | ✖ | ✖ | ✖ | ✖ |
| Открыть / завершить приём оценок | ✔ | ✖ | ✖ | ✖ | ✖ |
| Видеть итоги | ✔ | ✖ | ✖ | ✖ | ✖ |
| Оценить команду | ✖ ¹ | ◐ своя аудитория, приём открыт | ✖ | ✖ | ✖ |
| Поставить / снять «Не явилась» | ✔ | ◐ своя аудитория | ✖ | ✖ | ✖ |
| Настроить и опубликовать расписание, принять / отклонить отметку | ✔ | ✖ | ✖ | ✖ | ✖ |
| Поставить отметку | ✖ | ✖ | ✖ | ✖ | ◐ свои команды, сбор открыт |
| Видеть причину отметки | ✔ | ✖ | ✖ | ✖ | ◐ только автор (другие наставники — нет) |
| Видеть свой слот | — | — | — | ◐ после публикации | ◐ после публикации |
| Записаться на направление акселератора | — | — | — | ✔ | — |
| Видеть записавшихся | ✔ | ✖ | ◐ свои направления ² | ✖ | ✖ |
| Загрузить / удалить материал | ✖ | ✖ | ◐ свои направления, после окончания | ✖ | ✖ |
| Скачать материал | ✔ | ✖ | ◐ | ◐ записан на это направление | ✖ |
| Видеть анонс (все типы, в том числе акселератор) | ✔ | ✔ | ✔ | ✔ | ✔ |

¹ Организатор оценивает, только если он же эксперт аудитории (тогда действует строка «Эксперт»).
² Решение ПР8: тренер видит только ФИО и учебную группу записавшихся на свои направления.

Столбцы матрицы — роли, а не люди: «—» значит, что действие определяется другой ролью того же человека (студентом может быть и организатор, и наставник).

## Тексты отказа

- Заголовок: «Нет доступа».
- Организаторский раздел: «Этот раздел открыт только организаторам мероприятия.»
- Кнопка: «Вернуться в личный кабинет».
